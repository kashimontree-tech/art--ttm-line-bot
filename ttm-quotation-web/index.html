PDF พร้อมเปิดดูและแชร์

เปิดดูไฟล์ PDFบันทึกไฟล์นี้

ภาพตัวอย่างจากเอกสารที่สร้าง — กดเปิดดูไฟล์ PDF เพื่อตรวจทุกหน้า

กด “เตรียม PDF สำหรับแชร์” → ใส่ชื่อในหน้าต่าง → กด “ยืนยันชื่อและสร้าง PDF” → กด “แชร์ไฟล์ PDF” → เลือก LINE หรืออีเมล หากอุปกรณ์ไม่รองรับการแชร์ไฟล์ ให้กด “ดาวน์โหลด PDF” แล้วแชร์จากแอปไฟล์

ปุ่ม “บันทึกข้อมูล” เก็บในเครื่อง ส่วน “บันทึกลงคลาวด์” เก็บในฐานข้อมูลบัญชีอีเมลเดียวกัน ใช้อีเมลเดิมบนอุปกรณ์อื่นเพื่อเรียกข้อมูลได้
